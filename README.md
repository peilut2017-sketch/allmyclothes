# ארון המשפחה 👕

אפליקציית ווב לניהול ארון הבגדים של המשפחה – מה יש, לאיזה ילד, לאיזה גיל ולאיזו עונה.
בנויה כאתר מותאם-מובייל בעברית מלאה (RTL), עם חשבון פרטי לכל משפחה.

## מה יש באפליקציה

- **הארון** – כל הבגדים בתצוגת כרטיסים עם תמונות, חיפוש חופשי, סינון לפי ילד / עונה / קטגוריה / סוג / מידה / שנה / סטטוס, ומיון.
- **הוספת פריט** – צילום ישירות מהמצלמה או מהגלריה (התמונה נדחסת אוטומטית), שם, תיאור, שיוך לילד, עונה, מידה/גיל, קטגוריה (שבת/חול/פיג'מות + הוספה חופשית), סוג פריט (מכנס/אוברול... + הוספה חופשית), חנות/יצרן, מיקום אחסון (איזה ארון/מדף), מחיר, שנה, כמות וסטטוס.
- **רשימת קניות 🛒** – מה חסר ומה צריך לקנות, עם שיוך לילד, מידה ומחיר משוער; סימון ✓ אחרי הקנייה מעביר את הפריט ישר לארון, ואפשר לשתף את הרשימה בווטסאפ. כולל **מסך חוסרים חכם**: פריטים בסיסיים שאין לילד לעונה הקרובה, בלחיצה אחת לרשימה.
- **ארון משותף 👨‍👩‍👧‍👦** – שני הורים מנהלים ארון אחד: משתפים קוד הזמנה מההגדרות, ובן/בת הזוג מצטרפים מהחשבון שלהם.
- **התראת ״בקרוב קטן״ ⏰** – לפי גיל הילד מול המידה שעל הבגד, האפליקציה מסמנת בגדים שהילד עומד לצאת מהם.
- **החלפת עונה 🔄** – מעבר מודרך פריט-פריט בסוף עונה: נשאר בארון / עובר לאח / קטן מדי.
- **עד 4 תמונות לפריט 📸** – חזית, תווית מידה, מצב הבגד... עם בחירת תמונה ראשית וגלריה בהחלקה.
- **מצב כהה 🌙** – בהיר / כהה / אוטומטי לפי המכשיר.
- **ילדים** – כרטיס לכל ילד/ה עם צבע ואייקון מזהים, גיל מחושב מתאריך הלידה, וכמה בגדים יש בארון לכל עונה.
- **מעקב מחזור בגדים** – סטטוסים: בארון ✅ / שמור לגדילה 📦 / קטן מדי 📏 / הועבר הלאה 🎁, והעברת בגד בין אחים בלחיצה אחת.
- **שכפול פריט** – קניתם את אותו בגד בכמה מידות? שכפול מהיר בלי להקליד הכול מחדש.
- **סיכום** – כמה בגדים בארון, כמה הושקע, פילוח לפי ילד / עונה / קטגוריה / שנה.
- **גיבוי** – ייצוא כל הארון לקובץ CSV.
- מותקן כאפליקציה במסך הבית (PWA manifest).

## טכנולוגיות

React + TypeScript + Vite + Tailwind CSS, ומעל [Supabase](https://supabase.com):
אימות משתמשים, מסד נתונים (PostgreSQL עם Row Level Security – כל חשבון רואה רק את הנתונים שלו) ואחסון תמונות פרטי.

## הקמה – צעד אחר צעד

### 1. יצירת פרויקט Supabase

1. נרשמים/מתחברים ב-[supabase.com](https://supabase.com) ולוחצים **New project** (החינמי מספיק בהחלט).
2. אחרי שהפרויקט מוכן, נכנסים ל-**SQL Editor** → **New query**.
3. מעתיקים את כל התוכן של הקובץ [`supabase/schema.sql`](supabase/schema.sql) שבריפו, מדביקים ומריצים (**Run**).
   זה יוצר את הטבלאות, את חוקי האבטחה ואת מאגר התמונות.
   (אם הרצתם גרסה ישנה של הסכמה בעבר, הריצו גם את הקבצים שבתיקייה `supabase/migrations`.)
4. (מומלץ) ב-**Authentication → Sign In / Up → Email**: אם לא רוצים שלב אימות מייל בהרשמה, כבו את **Confirm email**.

### 2. הגדרת האפליקציה

```bash
npm install
cp .env.example .env
```

פותחים את `.env` וממלאים את שני הערכים מתוך **Project Settings → API** בלוח הבקרה של Supabase:

```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...
```

### 3. הרצה מקומית

```bash
npm run dev
```

### 4. פרסום לאינטרנט (Vercel / Netlify)

1. מחברים את הריפו ל-[Vercel](https://vercel.com) או [Netlify](https://netlify.com) (זיהוי אוטומטי של Vite).
2. מוסיפים בהגדרות הפרויקט את שני משתני הסביבה `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY`.
3. Deploy 🎉 – שולחים את הקישור לבני המשפחה, כל משפחה פותחת חשבון משלה.

> לנתיבי SPA ב-Netlify: הקובץ `public/_redirects` כבר כלול. ב-Vercel זה עובד אוטומטית.

## מבנה הקוד

```
supabase/schema.sql     סכמת מסד הנתונים + חוקי אבטחה (מריצים פעם אחת)
src/lib                 חיבור Supabase, טיפוסים, קבועים, דחיסת תמונות
src/context             AuthContext (התחברות) + DataContext (כל הנתונים והפעולות)
src/components          רכיבי UI משותפים (ניווט תחתון, כרטיס פריט, סינון...)
src/pages               המסכים: ארון, הוספה/עריכה, פריט, ילדים, סיכום, הגדרות
```
