# סרטון פרסומת – ארון המשפחה (Remotion)

סרטון אנכי 1080×1920, ‏30fps, ‏55 שניות, בעברית מלאה (RTL) עם פונט Heebo.
הפרויקט נפרד לגמרי מקוד האפליקציה – שום קובץ מחוץ לתיקייה `promo-v2` לא שונה.

## מה יש כאן

```
src/video.config.json   ← המקום המרכזי לעריכה: טקסטים, כתובת הרשמה, אורכי סצנות,
                          תזמוני פעולות (beats), אפקטים וקריינות
src/scenes/S1…S8        סצנה נפרדת לכל שלב בתסריט
src/app/                שחזור מסכי האפליקציה לפי הקוד האמיתי (ארון, פריט, ילדים,
                          החלפת עונה, קניות) + נתוני הדוגמה
src/components/         טלפון, בגדים וקטוריים, כותרות מונפשות, רקע, אייקון
audio/build_audio.py    פסקול מסונתז: מוזיקה, אפקטים והנמכה לקריינות
scripts/render.mjs      רינדור ל-MP4 + נרמול עוצמה ל-14- LUFS
scripts/vo_script.py    תסריט קריינות + קובץ SRT מתוזמן
```

## הרצה

```bash
cd promo-v2
npm install
npm run audio           # בונה את ערוצי הפסקול ל-public/audio (נדרש לפני studio)
npm run studio          # תצוגה מקדימה ועריכה בדפדפן (Remotion Studio)
npm run render          # → out/aron-hamishpacha-promo.mp4
```

דרישות: Node 18+, ‏Python 3 עם numpy + scipy, ‏ffmpeg.
Remotion מוריד דפדפן Chromium בעצמו בהרצה הראשונה (או מגדירים `REMOTION_BROWSER`).

## עריכות נפוצות

- **כתובת הרשמה בסיום** – `signupUrl` ב-`src/video.config.json` (ריק = לא מוצגת).
- **טקסטים** – תחת `copy` בכל סצנה. מילה בין כוכביות `*כך*` נצבעת בכתום המותג.
- **אורך סצנה** – `dur` (בשניות). תזמוני הפעולות (`beats`) יחסיים לתחילת הסצנה, והפסקול נבנה מאותם זמנים – כך שהכול נשאר מסונכרן.
- **אפקטים** – רשימת `sfx`: כל אפקט צמוד ל-beat של פעולה על המסך.

## קריינות

אי אפשר היה לייצר כאן קריינות אנושית אמיתית, ולכן הגרסה הנוכחית היא **מוזיקה ואפקטים בלבד**
(והיא בנויה להיות ברורה גם בלי סאונד). ערוץ הקריינות כבר מוכן:

1. `python3 scripts/vo_script.py` מפיק את התסריט עם הזמנים (`out/voiceover-script.md`) וקובץ `voiceover.srt`.
2. מקליטים ושומרים כ-`public/audio/vo.wav` – קובץ אחד באורך הסרטון, כל משפט בזמן שלו.
3. ב-`video.config.json` מגדירים `"voiceover": { "enabled": true }` ומריצים `npm run render -- --vo`.
   המוזיקה תונמך אוטומטית (`duckDb`) בכל חלון קריינות.
